# Play Store listing texts

One file per Play Console locale, each with the short description (80
characters max) and the full description (4000 characters max). `en-US.md` is
the source the other files are translated from; keep it in sync first when the
listing changes.

| File | Play Console locale |
|---|---|
| `en-US.md` | English (United States) |
| `de-DE.md` | Deutsch (Deutschland) |
| `es-ES.md` | Español (España) |
| `fr-FR.md` | Français (France) |
| `hi-IN.md` | हिन्दी (भारत) |
| `ar.md` | العربية |
| `zh-CN.md` | 中文 (简体) |

The screenshots and the feature graphic for the same locales are generated by
the pipeline described in [../STORE_ASSETS.md](../STORE_ASSETS.md).

Check the lengths after an edit:

```sh
python -c "import pathlib;[print(p.name, len(p.read_text(encoding='utf-8'))) for p in pathlib.Path('docs/store-listing').glob('*.md')]"
```
